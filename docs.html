Core documentation

Introduction

Memotrix is a composable hybrid memory / RAG library for agents — pip-installable, in the spirit of LangChain, but scoped specifically to memory.

At its center is one object, Memory, that composes three pluggable pieces: an embeddings model, a vector store, and a set of extractors that turn files into text. There is no default password, host, database name, embedding model, or embedding dimension — every one of those is supplied explicitly or read from the environment.

Installation

The package ships with optional install extras, so you only pull in what you use.

minimum install
pip install memotrix[memory]

In-process HNSW + BM25 hybrid search, plus local embeddings.

postgres + file extractors
pip install memotrix[postgres,memory,extractors]
editable (this repo)
pip install -e ./memory[postgres,local,embeddings,extractors,openai]

NO DEFAULTS

There is no default password, host, database name, embedding model, or embedding dimension. Every one of these must be set explicitly.

Quick start

Construct a Memory, add text, and search:

quickstart.py
from memotrix import Memory
from memotrix.embeddings import HuggingFaceEmbeddings, FakeEmbeddings
from memotrix.vectorstores import PostgresStore, InMemoryStore

embeddings = HuggingFaceEmbeddings(model="BAAI/bge-small-en-v1.5")
memory = Memory(
    embeddings=embeddings,
    store=InMemoryStore(embeddings),
)

memory.add_text("User prefers dark mode.", memory_type="semantic")
hits = memory.search("what theme does the user want?", top_k=3)
memory.delete("text:…")  # or the source_id you passed

Files work the same way:

files.py
memory.add("report.pdf")
hits = memory.search("what is the revenue?", filters={"memory_type": "semantic"})
print(memory.list_sources())
postgres.py
import os
from memotrix.vectorstores import PostgresStore

embeddings = HuggingFaceEmbeddings(model=os.environ["EMBEDDING_MODEL"])
memory = Memory(
    embeddings=embeddings,
    store=PostgresStore(connection=os.environ["DATABASE_URL"], embeddings=embeddings),
)
from_env.py
from memotrix import Memory
memory = Memory.from_env()  # fails if required vars are missing

Agent memory types

add_text is the path for facts, chat turns, and procedures — not only files. memory_type and session_id are exact-match payload filters.

memory_types.py
memory.add_text("Shipped hybrid search.", memory_type="episodic", session_id="2026-09-03")
memory.add_text("Always cite source_path.", memory_type="procedural")
memory.search("how should answers be cited?", memory_type="procedural")

Full detail on each type lives on the memory model page.

Custom extractors and embeddings

custom.py
memory = Memory(
    embeddings=embeddings,
    extract_file=my_extractor,  # (path, *, describe_images, generate_srt) -> DocumentData
)

OpenAIEmbeddings implements the same Embeddings ABC (install [openai]). HuggingFace remains the local default. Custom dense/sparse indexes can be passed as store= if they expose .dense and .sparse.

Environment config

Memory.from_env() reads configuration from environment variables and fails if a required one is missing:

VariableWhen
EMBEDDING_MODELalways for from_env()
DATABASE_URLor discrete DATABASE_* / POSTGRES_* parts, when MEMOTRIX_BACKEND=postgres
MEMOTRIX_BACKENDmemory (default) or postgres
RERANKER_MODELoptional
