Turning it on

Extractors are an install extra

File-type extraction isn't in the minimum install — it's pulled in explicitly:

terminal
pip install memotrix[postgres,memory,extractors]

memorylocal + embeddings (minimum to construct Memory)
extractorsPDF, Office, HTML, CSV, images, …
