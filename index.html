Quick start

A few lines to working memory

Construct a Memory object, add text or files, and search — no default host, password, or embedding model is assumed.

quickstart.py
from memotrix import Memory
from memotrix.embeddings import HuggingFaceEmbeddings
from memotrix.vectorstores import InMemoryStore

embeddings = HuggingFaceEmbeddings(model="BAAI/bge-small-en-v1.5")
memory = Memory(embeddings=embeddings, store=InMemoryStore(embeddings))

memory.add_text("User prefers dark mode.", memory_type="semantic")
hits = memory.search("what theme does the user want?", top_k=3)

The problem

Agent memory keeps getting rebuilt from scratch.

Facts, past conversations, procedures, and source files each end up with their own one-off storage and retrieval code. Memotrix gives agents one composable memory object instead.
