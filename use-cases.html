Use cases

Where teams put Memotrix to work.

Anywhere an agent needs to remember: facts, past turns, standing rules, or the contents of files handed to it.

Agent loops

Give a tool-using agent persistent semantic and episodic memory across turns and sessions.

see examples/03_agent_loop.py

RAG systems

Point memory.add() at a folder of files and retrieve relevant chunks to ground generated answers.

see examples/02_files_postgres.py

Coding assistants

Retrieve source code and its surrounding documentation together, in one search call.

e.g. filters={"memory_type": "procedural"}

Enterprise knowledge

Unify documents, email, and chat exports into one searchable memory layer with source tracing.

e.g. memory.list_sources()

Domain apps

Marine, education, finance and medical apps already ingest domain-specific files with memory.add(path) and store free-form notes with memory.add_text(...).

confirmed in the project README

Research systems

Retrieve papers, datasets and notes across a body of work using hybrid similarity search.

e.g. top_k tuning per query

Multimodal AI

Reason over images, audio (via Whisper) and text as one memory, using the extractors and audio extras.

pip install memotrix[extractors,audio]
